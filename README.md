# 📱 Mobile Store

A Windows Forms desktop application built in C# with SQL Server, designed to simulate a real-world mobile phone retail system.

## 🚀 Features
- Browse phones with a card-based UI
- Multi-filter search (brand, price, specs)
- Phone details page
- Compare two phones side by side
- Admin panel to add, edit, and delete phones
- Secure login with SHA-256 password hashing
- Async data loading for smooth performance
- Order management system

## 🏗️ Architecture
Built with a clean 3-layer architecture:
- **DAL** — Data Access Layer (SQL Server)
- **BAL** — Business Access Layer
- **Presentation** — Windows Forms UI

## 🛠️ Tech Stack
- C# / .NET Windows Forms
- SQL Server
- ADO.NET
